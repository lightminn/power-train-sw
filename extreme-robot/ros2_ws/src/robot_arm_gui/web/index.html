전류 raw 1 LSB ≈ 2.69 mA. 온도는 라운드로빈 2 Hz 라 모터별 갱신이 느리고, 0 은 “0 °C”가 아니라 아직 폴링이 안 닿았다는 뜻이라 — 로 표시합니다.

비전

영상 꺼짐. raw 는 인식 노드가 어차피 항상 발행하는 원본이라 켜도 그쪽 부하가 늘지 않습니다 (검출 박스는 이 화면이 대신 그립니다). debug 는 켜는 동안에만 인식 노드가 마스크·거리 오버레이를 그립니다. wrist·wrist_debug 는 손목 캠(`wrist_camera` 노드)입니다 — 노드가 안 떠 있으면 프레임이 안 올 뿐, 다른 소스에는 영향이 없습니다.

    원격조종

    ⚠ 관측 불가 — 이 화면으로 알 수 없는 것

      관절 캘리브레이션

      순서는 기어비 → 영점 → 가동범위입니다. 기어비가 틀리면 영점 역산이 같이 틀어지고, 둘 중 하나라도 바뀌면 기존 가동범위는 전부 무효입니다. ⚠️ 여기 값은 전부 관절각 도메인(JOINT_CONFIG· joint_limits)입니다 — teleop_core 의 DEFAULT_CENTERS/DEFAULT_*_RADS(서보축 도메인)와 숫자가 무관하니 서로 복사하지 마세요. 브릿지는 read_only:=true 로 띄워 두세요(토크가 꺼져 있어야 손으로 움직입니다).

      ① 기어비
      —

      시작 캡처 → 관절을 크게(90° 권장) 손으로 돌림 → 끝 캡처 → 실제 각도 입력. 각도계 오차가 그대로 기어비 오차가 됩니다.

      ② 영점 (center tick)

      팔을 기준 자세(기본 URDF home = 전 축 0)로 세운 뒤 계산을 누르세요. 구조상 0 으로 못 세우는 축은 아래에 기준각을 넣습니다.

      —
      ③ 그리퍼 끝단
      —

      ⚠️ 랙 끝단에 억지로 밀어 넣지 마세요 — 그 지점이 끝단으로 박히면 운용 중 매번 거기까지 가려 들고, 그리퍼는 과전류 트립이 잘 납니다.

      ④ 가동범위 (리밋)

      이 절차는 teleop_core 가 수행하고 결과를 ~/ros2_ws/dynamixel_arm_joint_limits.json 에 자동 저장합니다. 시작하면 팔 토크가 꺼집니다 — 축을 손으로 하한까지 밀고 [기록], 상한까지 밀고 [기록]을 축마다 반복하세요.
