# 2026-10-14 볼 잠금 엔드이펙터 URDF 반영

입력: 사용자 제공 `new_robot_arm_description.zip`.
기존 `dual_motor_gripper` 모델을 교체하고 단일모터 모델은 유지했다.
원본의 모든 링크·관절 좌표, 축, 질량·관성 및 STL을 유지했다.
잠금 로터는 후속 사용자 확인(양방향 반복 22.5° 인덱싱)에 따라 continuous로 변경했다.
팔 관절 이름은 `arm_joint_1..5`, 그리퍼 관절은 기존 이름으로 대응했다.
새 메쉬는 `meshes/ball_lock/`에 분리해 기존 단일모터 메쉬를 덮어쓰지 않는다.

## 손목과 결합부

- `arm_joint_5`: 손목 회전, 로컬 X축, 원본 범위 -3.14159~3.14159 rad.
- `toolchanger_lock_wheel`: 별도 잠금 로터, 로컬 X축, 양방향 반복 회전.
  원본 CAD의 0~22.5° 범위는 한 번의 결합/분리 전환 구간이다.
  제어는 XL430 ID1, 1:1이며 22.5°를 256 tick으로 환산한다.
- `lock_ball_1..8`: 방사 방향의 볼 이동, 각 0~0.00259 m.
- 로터와 볼은 독립 관절로 가져왔다. 원본에는 mimic/캠 프로파일이 없어
  선형 연동식이나 결합·분리 상태를 임의로 추가하지 않았다.
- URDF는 연결된 트리이며 실제 도구 탈착이나 모터 명령을 수행하지 않는다.

## 실기 적용 전 주의

새 CAD는 손목 외에도 베이스·팔 좌표, 관절 축 및 한계가 달라졌다.
특히 `arm_joint_2/3` 범위는 기존 0~π 대신 -3.14159~0이다.
실기 bridge의 tick 변환, `joint_limits.py`, 영점·방향 및 카메라 캘리브레이션을
아직 변경/검증하지 않았다. 기존 실기 설정으로 새 모델을 바로 구동하지 않는다.

`link_043`/`link_051`은 새 `arm_link5` 원점에 고정된 이름 호환용 프레임이다.
기존 TCP 좌표·접근축과 동일하다는 뜻이 아니므로 IK/파지 캘리브레이션을 다시 한다.
새 파일에 손목 카메라가 없어 `wrist_camera_link`는 새 모델에 없다.
손목 카메라의 장착 좌표가 확보되기 전에는 손목 영상의 TF 기반 파지를 사용하지 않는다.

SRDF의 오래된 링크 참조를 제거하고 새 부모-자식 Adjacent 충돌쌍만 생성했다.
기어/볼의 실제 접촉쌍과 자세별 자기충돌, home 자세 유효성은 별도 확인한다.
그리퍼 피니언/랙도 원본의 독립 관절이다. 과거 모델의 mimic 비율은 새 CAD에 적용하지 않았다.
ID1 제어 브리지는 로터의 영점 대비 encoder 각도를 발행한다.
볼·종속 그리퍼 관절의 위치 연동은 여전히 미구현이다.

## 검증 상태

정적 검사 4개와 격리된 로컬 MoveIt/RViz 실행을 확인했다.
현재 joint4가 내려간 자세에서 내부 접촉 10쌍을 임시 제외하고
joint4 ±0.02 rad 왕복 PTP 계획·mock 실행이 통과했다.
OMPL 시간초과와 전체 축 검증, 실기 검증은 미완료다.
조건 및 관절값은 저장소 `docs/reports/2026-10-14-arm-ball-lock-moveit-check.md`를 따른다.
