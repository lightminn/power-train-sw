# PR #12 통합 콘솔 로컬 실물 시험

## 적용 범위

`agent/local-arm-gui-test`에서 upstream/main과 PR #12 작업본을 통합했다.
사용자 요청에 따라 GUI는 `operator_console` 통합 운용 콘솔로 고정했다.
현재 로컬 USB에서응답하는 모터는ID1·ID16뿐이다. ID11·14·13·12는미응답이며,
1~4축의 기존영점·감속비·설정은 변경하지 않았다. 전체팔 장착시험과Jetson 연결시험은 아니다.

## 영점·시험 설정

- 사용자 확인5축영점2525 tick, 볼락잠김3051 tick을 런타임에 적용했다.
  Homing Offset·NVM 캘리브레이션은 쓰지 않았다.
- ID1은속도모드1에서위치모드3으로 변경했고 유지한다.
- ID1 Position P Gain은위치모드초기값640에서2000으로 RAM 조정했다.
  최초저속시험에서22.5° 목표보다0.97° 미달했고, GUI 초기왕복도정착오차로 시간초과됐다.
  허용오차를 늘려완료시키지 않고 최종설정은기본4 tick을 유지했다.
- ID1·16 Goal PWM은 RAM200,5축 Profile Velocity3·Acceleration2다.
  기존EEPROM PWM Limit885는 변경하지 않았다.
- 5축조그는±114 tick(±10.01953125°), 갱신당최대12 tick으로 제한한다.
  현재명령TTL0.6초, 브리지수용가능한미래만료상한1초, 데드맨점검주기0.05초다.
  같은호스트와Docker의단조시각전용이며Jetson원격조그에그대로쓰지 않는다.

## 수정과 실제 실행 검증

- GUI누름갱신, 인증ops최종ACK의조그슬롯해제, GUI재기동시새순서번호를 연결했다.
- 잠금휠의별도`/joint_states` 메시지가팔5축상태를덮어써조그권한을끊던결함을 수정했다.
- 기본FULL_ROBOT 잠금거부는유지한다. 명시적수동옵션에서만정지한연결팔축을확인한뒤
  잠금제어를허용한다. 조그중잠금전환과잠금미준비중팔명령은거부한다.
- 실제PR #12 GTK버튼→인증TCP127.0.0.1:19001→설치ROS→실물USB→ROS→UDP15707→GTK를 실행했다.
- 5축누름조그8회갱신:6.15234375°→4.04296875°,놓은뒤정지했다.
- 볼락해제목표2795 tick에도달허용오차내2799 tick/UNLOCKED를확인했다.
  재결합목표3051 tick은3048 tick/LOCKED로완료했다. 명령스트로크는각256 tick(22.5°)이다.
- 키보드텔레옵STOP에서두시험모터토크OFF를확인했다.
  잠금활성화후현재위치RESUME을실행했고설치브리지의5축토크ON레지스터대조가통과했다.
- 최종화면은실제LIVE통합콘솔의로봇팔수동조작탭이다. 도구ID5는미연결로표시되며
  해당그리퍼버튼은비활성이다. 실제결합센서는없고LOCKED는인덱스판정이다.

## 현재 실행과 제한

컨테이너`arm_local_gui_20261017`,ROS_DOMAIN_ID77,실물브리지와인증브로커·상태미러가실행중이다.
5축과볼락은최종재활성화뒤토크ON으로현재위치를유지한다.
화면을닫은후같은런타임의GUI만다시열려면호스트레포에서
`bash scripts/open_local_arm_console.sh`를사용한다. 시험명령자동실행은하지않는다.
`/tmp/arm-gui-session`의토큰과설치런타임은임시이며재부팅뒤유지된다고가정하지않는다.

로컬팔정지는키보드텔레옵의정지버튼을사용한다. 상단전역긴급정지는차체ops경로이며,
이독립팔벤치에는차체서비스가없다. 전체팔·차체통합비상정지인수는이번범위가아니다.
