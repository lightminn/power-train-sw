## 설계와 달라진 것

- **점–평면 ICP 보정을 기본에서 뺐다.** 합성 시험(60프레임, 1.2 m)에서 오도메트리만 쓰면 이동 오차 최대 2.6 mm·회전 0.10°였는데, ICP로 보정하면 53 mm·0.95°로 나빠졌다. 바닥이 화면 대부분인 장면에서 기하만으로는 바닥면 안 이동이 퇴화해 미끄러진다. ICP는 수용 판정용 지표(fitness·RMSE·정보 행렬 고유값)만 잰다. 보정은 `--refine icp` 선택지로 남겼다. 밝기 포함 ICP는 두 번째 프레임부터 발산해 넣지 않았다
- 옛 `ScalableTSDFVolume`은 Open3D 0.20 pip판에서 점을 하나도 내지 않아(균일 격자판은 됨) 텐서 VoxelBlockGrid로 바꿨다. 깊이는 uint16(단위 0.25 mm), 밝기는 uint8 3채널이어야 한다
- IMU 중력 정렬은 아직 쓰지 않는다(L515 IMU 보정 전 바닥 법선과 1.74° 차이)

## L2 장애물 분류 — `lidar_dev/obstacles_map.py`

| 항목 | 내용 |
|---|---|
| 입력 | map_seq 출력(지도 점·자세·요약) + 기준값 JSON(`lidar_dev/config/obstacle_criteria_v0.json`, v0.1, profile l2-exp-v1 — 시뮬 담당 정본과 같은 파일). 값을 코드에 옮겨 적지 않는다 |
| 격자 | 5 cm 칸, 칸별 윗면(90 분위)·아래(10 분위)·점 수. 천장 등 2 m 위 점 제외 |
| 관측 상태 | v1: 표면 점이 있는 칸 = 관측, 없으면 미확인, 카메라 궤적에서 4 m 밖 미확인(광선으로 빈 공간을 지우는 FREE는 아직 없음) |
| 지지면 구역 | 칸 안 높이 범위 > 3 cm인 **모서리 칸**은 빼고, 이웃 높이 차 < 3 cm로 이어진 칸을 구역으로 묶는다. 가장 큰 구역 = 지면. 모서리 칸을 빼지 않으면 5 cm 상자가 섞인 칸을 계단 삼아 지면과 이어진다(첫 판에서 확인) |
| 분류 | 지면: 30 cm 창 경사·거칠기(지면 칸만으로 평면 맞춤 — 물체가 창에 섞이면 거칠기로 잘못 걸림). 다른 구역: 둘레와의 높이 차 → 턱(오르기)·내려가기·벽(0.5 m). 모서리 칸: 칸 안 높이 범위를 턱 높이로. 주의·불가 칸이 이어지면 한 물체(단계는 가장 나쁜 것) |
| 출력 | `terrain_map.json`(type terrain_map, schema 1, 기준값 버전, 좌표 정의, 칸 수, 미지원 목록, 물체별 단계·면적·중심·단차·윗면·이유·`poly_xy_m`), `terrain_grid.npz`, `terrain_top.png` |
| 미지원 | 통로 폭·머리 위 높이(2.5D로 표현 못함), 기준값 v0.1 미지원 지형 |
