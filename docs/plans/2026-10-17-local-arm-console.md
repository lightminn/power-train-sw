# 로컬 통합 콘솔 연결·검증

1. PR #12 기능을 별도 로컬 브랜치에 통합하고 기본 게이트를 유지한다.
2. 새5축·볼락 영점을 런타임 파라미터로 적용한다. 1~4축은 재캘리브레이션하지 않는다.
3. 통합 콘솔의5축 hold/ACK/refresh/release와 볼락 카드를 인증 ops에 연결한다.
4. 설치 ROS 엔트리포인트와 실제 GTK 버튼에서 모터 이동·피드백을 확인한다.
5. 만료·순서·축 제한·기존 잠금 게이트를 테스트하고, 만료 검사 제거 음성 대조를 실행한다.
6. 전체 콘솔 runtime_smoke와 실제 화면을 확인하고 결과·현재 토크 상태를 남긴다.

시험 설정: `config/local_arm_wrist_console.yaml`.
