# 콘솔 조향 조작 적용 계획

정본: `docs/specs/2026-09-10-console-steering-controls.md`

1. 기존 스키드 선택의 브로커 상태 전달 누락을 수정한다. 완료, 관련 테스트 및 GTK 실행 확인.
2. 차체/AK 드라이버의 IDLE 원점 등록과 콘솔/ops/ROS 연결을 구현한다. 병렬 분담: 모터 코어와 콘솔 어댑터, 공유 인터페이스 `register_steering_origin() -> (success, detail)`.
3. 최신 사용자 지시에 따라 긴 전체 시험은 미루고 빠른 검사 후 운용 체크아웃에 백업·적용한다. 팀원 체크아웃은 보존한다.
4. 필요한 차체/제어 서비스와 로컬 콘솔을 재기동하고 연결·버튼 상태를 확인한다. 실제 버튼 저장 및 주행은 사용자가 수행한다.

판정: 이전 운용 세션 배포 보류 지시는 최신 `바로 실투입` 지시로 대체됐다. 자동 시동/실물 모터 시험은 수행하지 않는다. 커밋·푸시는 이번 지시에 포함하지 않는다.
