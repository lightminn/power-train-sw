# 통합 콘솔 잠금 카드 작업 계획·실행 기록

정본 설계: docs/specs/2026-10-16-console-coupling-lock.md.
사용자 요청으로 통합 콘솔의 수동조작 탭에 기존 Qt 잠금 패널을 옮긴다.

1. 기존 디자인 카드와 callback/state 계약에 잠금 패널을 추가한다.
   검증: 실제 GTK 버튼·상태 지연·미연결·개발자 모드에서도 게이트 보존.
2. 기존 인증 ops 및 관측 UDP에 좁은 잠금 어휘를 연결한다.
   검증: 설치 빌드, 브로커 입력 검증, 실제 GTK→ops→ROS mock→UDP→GTK 실행.
3. 표시와 실패 보호를 확인하고 수정된 콘솔을 사용자 화면에 연다.
   검증: runtime_smoke, 1600×900 실제 GTK 렌더, 알려진 범위 게이트 제거 시 실패 확인.

실행 결과는 docs/reports/2026-10-16-console-coupling-lock.md에 기록한다.
실제 하드웨어 교체 인수는 원래 계획 §5-5에 남는다.
