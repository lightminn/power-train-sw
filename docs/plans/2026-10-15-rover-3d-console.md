# GUI 차체 3D 적용 기록

- [x] 디스크 여유 재확인, 메모리 임시 검토 자료를 디스크에 보존.
- [x] 정상 확인된 첨부 URDF의 39개 표시 메시를 인덱스 형식으로 변환. 부품·관절 이름을 유지.
- [x] Three.js 0.186.1 파일과 MIT 라이선스를 번들하고 WebKit을 탭 표시 시 시작.
- [x] 기존 `협조구동 → 6륜 제어 상태` 카드에 3D 렌더러, 모터/IMU 수신값, 바퀴 팝업 연결. 최초 별도 탭 배치는 사용자 정정에 따라 제거.
- [x] 선택 관절각 필드·표본 나이 검증과 갱신 중단 표시.
- [x] 격리된 실제 GUI 수신 경로 스모크 및 기존 GUI 검사 수행.
- [x] 기존 실패를 이번 변경을 제거한 메모리 오버레이에서도 재현해 회귀와 구분.
- [x] 운영 콘솔 재기동과 캡처 확인. 이후 같은 협조구동 카드에서 더미 엔코더 연속 시연.

실물 관절 엔코더 수신, 디퍼렌셜 연결봉 폐루프 해석, 장시간 영상 동시 부하는 후속 범위다. 실측 없이 해당 기능이 검증된 것으로 표시하지 않는다.

- [x] 원본 관절 좌표를 유지한 1,368삼각형 간략 모델로 교체, CAD 메시 다운로드 제거.
- [x] 변경 시 렌더링/20fps 제한/동일 수신값 전달 병합, 줌·팬 비활성 및 회전 유지.
- [x] Noto 글꼴과 확대 글씨, 기술 상세 숨김, 단순 모터 팝업.
- [x] 경량 GUI UDP 스모크·12개 관련 검사·글꼴/회전/성능/창 맞춤 검사 및 데스크톱 시연 재기동.

- [x] 후속 형상 보완: 원통형 로커/보기, 차체 패널, 조향 실린더, 트레드·스포크·허브 추가. 반복 형상은 instancing으로 묶음.
- [x] 6,440삼각형/1만 미만, 기존 UDP→관절→팝업→단절 검사 PASS. 회전·줌 차단과 크기 검사 재수행.

- [x] 0°/180° 실제 WebKit 캡처로 고정 편측 조명과 flat shading의 차이를 재현.
- [x] 시점 기준 주/보조광, 주변광, Z-up 반구광 및 부드러운 원통 표면 적용.
- [x] 반대 시점 비교·경량 성능·관절/팝업/단절 검사 재수행.

- [x] 원본 CAD 표시 LOD 생성, 원본 변환과 경계 손실·자산 크기 확인.
- [x] 도형 대신 CAD LOD 연결 및 바퀴 재질/모터 상태 표시 유지.
- [x] 실제 형상, 180° 회전, 더미 관절, 팝업 및 렌더링 성능 검증 후 GUI 재기동.

- [x] 원본 CAD 디테일 유지, 작은 삼각형 경계의 표시 법선 정리.
- [x] 기본/180° 외관, 줌 차단, 관절/팝업/단절 및 경량 성능 재확인 후 GUI 재기동.
