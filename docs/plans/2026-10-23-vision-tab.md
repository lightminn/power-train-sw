실행 설정·대기열·글자 캐시·성능 계측은 [5단계 보고서](../reports/2026-10-24-vision-tab-step5.md)를 따른다.

## 결정 대기와 미해결 사항

1. cv2: 다음 단계 진행 요청에 따라 (a) 기존 함수 재사용 방식을 선택했다.
   관리자 권한 없이 시스템 Python의 사용자 패키지 영역에 numpy/OpenCV-headless/pytest를 설치했다.
   NumPy 공용 모듈 추출이나 lidar_dev 코드 변경은 하지 않았다.
2. 장착 보정: 각도 하나뿐 아니라 좌표·부호·영점·회전 적용 위치 확인 필요.
   확인 전에는 원시 IMU 표시로 진행 가능하다.
3. 실제 바닥 영역 칠하기는 현재 :5009 데이터로 불가능. 상태 배지와 장애물 윤곽은 재사용 가능.
   바닥 영역 계약이 추가되기 전에는 요구 충족으로 체크하지 않는다.
4. Jetson 접속 주소·연결은 미확인. `ssh jetson` 이름 해석 실패.
5. 환경 준비 후 구현 전 기준선은 771 passed / 11 failed / 3 skipped였다.
   runtime_smoke의 기존 arm safe-disabled 실패를 포함한다. 이후 결과는 2단계 보고서에 기록한다.
