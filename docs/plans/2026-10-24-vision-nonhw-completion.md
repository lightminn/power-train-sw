# 비전 HW 제외 잔여 작업

사용자: HW 검증을 제외한 남은 일을 모두 처리.

1. [x] 메모리 추적 하니스·원시 스트리밍 기록·저장량 상한, 숨김/정지 진단 추가.
2. [x] 기존 :5009 경로의 선택 바닥 격자 송신/파싱/공유 표시와 호환/오류 검사.
3. [x] 기본 비활성 보정 JSON/CLI/환경 설정, 합의 후 회전/정지 참고 비교 경로.
4. [ ] 실제 GTK/전체 회귀·고장 대조 완료 및 동일 입력 최적화 전/후 비교.
5. [ ] AC 합성 600초 장시간 시험·RSS 추세 확인·문서/PR 저장.

설계: [비HW 잔여 구현](../specs/2026-10-24-vision-nonhw-completion.md).
실제 Gateway/L515 시험·로봇 배포/재시작은 수행하지 않는다.
광민·도현의 실제 보정 합의와 AS5048B 실제 송신은 임의로 만들지 않는다.
기존 로봇팔 계약 실패는 비전 회귀와 구분하며 승인 없는 타 팀 제어 계약 변경으로 숨기지 않는다.
