# 콘솔 조향 방식 선택과 현재 자세 영점 등록

사용자 요청: 스키드 선택을 콘솔에 연결하고, IDLE에서 현재 조향 4축 자세를 영점으로 저장한다. 2026-09-10 추가 지시로 긴 시험 대기 없이 구현 후 실투입한다.

- 조향 방식은 기존 `steer_mode_skid`와 정지·0° 수렴 절차를 사용한다. 브로커는 실제 모드·조향 가용성·전송 방식을 전달하며 오래된 정보는 비활성화한다.
- `복구 · 설정`의 `현재 조향각을 영점으로 저장`은 확인 후 console 토큰으로 `steer_zero_here` Trigger를 호출한다.
- 브로커와 차체에서 IDLE·정지·최신 피드백을 확인한다. 차체의 기존 CAN 소유자가 AK 1~4에 원점 명령만 보낸다. 구동·위치·시동 명령은 보내지 않는다.
- 모든 축을 사전 확인한 뒤 쓰며, 명령 이후 새 피드백이 모두 0° 부근일 때만 성공이다. 부분 실패는 오류로 보고하고 자동 재시도·위치 복원하지 않는다.
- 사용자가 현재 바퀴의 직진 정렬을 확인한다. 전원 재인가 후 원점 유지 여부는 별도 실기 확인이다.
