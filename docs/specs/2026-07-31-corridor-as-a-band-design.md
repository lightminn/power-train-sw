# 코리도를 스칼라 한 쌍이 아니라 x의 띠로 — 설계

작성 2026-07-31. 대상 `powertrain_autonomy/terrain/estimator.py::_summarize`.
근거 데이터: 실코스(`course.stl`) z0.55 마운트 주행 중 저장한 격자 12프레임
(`runs/multigrid/grid_00..11.npz`), 그리고 120런 373,500틱의 사유 집계.

## 1. 무엇이 문제인가

지금 코리도는 계획창(0.35~2.50 m) 전체에 적용되는 **스칼라 두 개**다:

```python
right_corridor = median(행별 우측 support 에지)
left_corridor  = median(행별 좌측 support 에지)
```

이 median이 합치려는 양은 두 가지 서로 다른 것이 섞여 있고, 게다가 x의 함수다.

### 1.1 섞인 두 가지

행마다 얻는 support 에지는 둘 중 하나다.

- **측정** — 그 에지 너머로 낙하가 관측됐다. "트랙이 여기서 끝난다."
- **한계** — 관측이 거기서 멈췄다. "여기까진 지면인 걸 봤다, 그 너머는 모른다."

전자는 트랙 에지의 **추정치**고, 후자는 **한쪽 부등식**(트랙은 최소한 이만큼 넓다)이다.
부등식들의 median은 아무 의미가 없다. 그런데 코드는 인증된 행이 하나도 없으면
전부를 같은 median에 넣는다:

```python
else:
    right_corridor = float(np.median([row[1] for row in candidate_rows]))
    boundary_degradation.append("right_edge_unverified")
```

아무도 인증 못 하면 **아무것도 못 본 행까지 투표한다.**

### 1.2 x의 함수

프레임 0(t=1.10)의 좌측 낙하 위치를 행별로 읽으면:

```
x=1.33  support 가 y=+0.93 까지, 낙하 미관측 (관측 한계)
x=1.83  낙하 F 가 y≈+0.68 바깥, 높이 -1.054 (0.44 m 낙차)
x=2.42  낙하 F 가 y≈+0.68
x=3.33  더 안쪽
```

트랙 좌측 에지가 x에 따라 실제로 안쪽으로 들어온다. 스칼라 하나로 표현할 수 없다.

## 2. 측정된 증상

### 2.1 median: 간헐적 한쪽 붕괴

12프레임 중 3개에서 우측 경계가 0.65 m 안쪽으로 무너진다. 무너진 프레임은
정확히 "계획창 밖 행 비율이 높은" 프레임들이다.

| 프레임 | 계획창 밖 행 | 코리도 폭 | 침식 여유 |
|---|---|---|---|
| 3 (t=8.60) | 51% | 0.400 m | **−0.489** |
| 8 (t=21.10) | 47% | 0.250 m | **−0.639** |
| 9 (t=23.60) | 46% | 0.250 m | **−0.639** |
| 정상 8프레임 | 0~19% | 0.95~1.00 m | +0.06~+0.11 |

침식 여유 음수 = `erosion_empty`. 120런 전체 기각 사유의 88%(35,751회)가 이것이다.

프레임 3의 붕괴를 만든 행들을 직접 보면 기하가 아니라 관측 구멍이다:

```
x=1.83   FFFFF.....SSSSSSSSSSSSSSSSSSSS..........   높이 -0.055
x=2.23   FFFF..................SSSSSSSS......FFFF   ← y -0.45~+0.12 은 valid 도 아님
x=3.33   vF......................SSSSSS........FF   ← 여전히 없음
x=3.83   vvvv.....SSSSSSSSSSSSSSSSSSSSS........FF   높이 -0.051  ← 같은 지면 복귀
```

앞뒤 행이 같은 높이로 지면 연속을 증명한다. 가운데 행들의 우측 에지 +0.12 는
"트랙이 끝난다"가 아니라 "왼쪽을 못 봤다"인데, median 이 그걸 트랙 에지로 받는다.

### 2.2 widest: 반대 방향 과대주장

미인증 에지를 한쪽 부등식으로 보고 가장 넓은 것으로 합치면 붕괴 3건은 전부
사라지고(코리도 1.000~1.050 m) 정상 프레임도 실제 트랙폭에 맞게 조여진다.
그러나 프레임 0·1·2 에서는 근거리의 넓은 관측을 원거리까지 적용해 코리도가
1.30~1.95 m 가 되고, 그 안에 실제 낙하가 들어와 choke 필터가 발화한다.

**median 도 widest 도 틀렸다.** 합치려는 양이 x 의 함수인데 스칼라로 합치기 때문이다.

## 3. 설계

측면별로 코리도를 **x 의 1차 띠**로 둔다.

```
right(x) = a_r + b_r·x
left(x)  = a_l + b_l·x
```

행별 에지는 종류에 따라 다르게 쓴다.

- **측정**(인증된 에지): 적합의 관측점.
- **한계**(미인증 에지): 적합을 안쪽으로 당기지 못하는 한쪽 제약.
  우측이면 `right(x_i) ≤ e_i`, 좌측이면 `left(x_i) ≥ e_i`.

적합 절차:

1. 인증 행이 2개 이상 → 그 행들로 최소제곱 적합, 잔차 2셀(0.10 m) 초과 행을
   한 번 잘라내고 재적합.
2. 인증 행이 1개 → 그 에지의 상수(b=0).
3. 인증 행이 0개 → 그 측면은 관측되지 않았다. 한쪽 제약들의 극단값(우측 min,
   좌측 max)을 상수로 쓰고 `*_edge_unverified` 로 표시한다.

그 뒤 제약을 강제한다: 각 행에서 띠가 그 행의 관측 support 보다 **좁게** 나오면
(측정된 지면을 지면이 아니라고 주장하는 것) 그 행의 에지까지 넓힌다.

## 4. 이 설계가 지우는 것

`_summarize` 의 코리도 관련 약 190줄 중 대부분이 스칼라 모델을 떠받치려고
붙은 특례다. 띠 모델에서는 존재 이유가 사라진다.

| 지금 | 왜 있었나 | 띠 모델에서 |
|---|---|---|
| 코리도 fallback 분기 2개 | 인증 없을 때 뭘 쓸지 | 적합 3번 경우로 흡수 |
| 일관성 필터(2셀 밴드) | 스칼라에서 벗어난 에지 = 파편으로 간주 | 적합의 잔차 절단이 대체 |
| `effective_right/left` 상속 | 행이 스칼라를 물려받게 | 띠를 그 행의 x 에서 평가 |
| 코리도 폭 prior 중심 복원 | 한쪽만 실측일 때 중심 추정 | 중심 = ½(right(x)+left(x)) |
| direct-row basis fallback | 상속 행이 기울기를 오염 | 기울기 = 띠의 기울기, 직접 |
| per-side unverified clamp | 미관측 측면의 음수 clearance | 3번 경우가 곧 그 표시 |

또한 전역 게이트 3개가 행별로 내려간다 — 있어야 할 자리다.

- `erosion_empty` 전역 판정 → 행별 `safe_right(x) ≤ safe_left(x)`.
  통과 행이 `min_path_rows` 미만이면 기존 기각으로 자연히 귀결되므로 전역 검사는 삭제.
- `obstacle_blocks_path` 의 `corridor_cols` → 행별 열 범위.
- choke 의 `inner_columns` → 행별 열 범위. 지금은 근거리 코리도로 만든 열 마스크를
  격자 전체 깊이(4.0 m)에 적용해서, 계획창 밖 낙하가 근거리 프레임을 기각시킨다.

예상 규모: `_summarize` 코리도 부분 약 190줄 → 약 80줄.

## 5. 보존해야 하는 안전 성질 (변경 금지)

1. 인증된 에지(너머로 낙하 관측) 바깥으로 코리도가 나가지 않는다.
2. 관측된 support 를 지면이 아니라고 주장하지 않는다.
3. 한 측면도 인증되지 않았으면 그 사실이 degradation 사유로 나간다.
4. 인증된 측면의 음수 clearance 는 실제 이탈이므로 그대로 보고한다(`ea42ea4`).
5. 코리도 안의 장애물·낙하는 계속 프레임을 기각한다.

## 6. 판정 기준

단일 실행으로 판정하지 않는다 — 실코스 단일값은 분포의 최댓값이었던 전례가 있다
(보고했던 2.355 vs 실제 중앙값 0.868).

- 8패밀리 + `narrow_curve` 캠페인: `edge_overrun 0`, `fail_open 0` 유지가 하드 게이트.
- 스윕 하네스(`sweep_run.sh`)로 시드·스폰 표본을 뽑아 **중앙값과 스프레드**로 비교.
- 12프레임 오프라인 재현에서 붕괴 3건이 사라지고 프레임 0·1·2 의 choke 가
  발화하지 않아야 한다.

## 7. 남는 위험

띠는 1차다. 트랙이 계획창 안에서 곡률을 크게 바꾸면 1차로는 부족하다. 실코스
12프레임 범위에서는 1차로 충분했으나, 더 급한 곡선에서 잔차가 커지면 차수를
올리는 것이 아니라 **계획창을 줄이는 쪽**을 먼저 검토한다 — 차수를 올리면 이
설계가 없애려는 특례가 다시 생긴다.
