# PR #20 메인 GUI의 팔 제어

실행 진입점은 기존 `operator_console`이다. 별도 Qt 제어 창이나 직접 ROS 전송 경로를 추가하지 않는다.

- PR #20의 비전·지형 지도·협조구동·시스템·3D 화면을 유지한다.
- 팔 수동조작 탭은 PR #14의 키보드 1~5축, 숫자패드, 제한/트립 토글, 자세 저장·이동·삭제·home·자유 지정,
  볼락 2점 결합/해제, 슬롯 teach/교체, 도구 개별/동기 제어와 패드 조작을 사용한다.
- PR #20의 팔 3D 자세 카드는 유지하고 바로 아래에 패드 선택과 안내를 배치한다.
- 키 입력은 팔 수동조작 탭에서만 활성이다. 다른 탭·포커스 이탈 시 기존 해제 경로를 유지한다.
- 조작은 기존 인증 ops → ROS 브로커 → 팔 브리지로 전달한다. 브리지·브로커·콘솔은 같은 통합 체크아웃으로 설치한다.
- 벤치 스위치·세션 JSON·기록된 자세·볼락·슬롯 파일은 기존 것을 사용한다. 저장 파일을 기본 예제로 덮어쓰지 않는다.

상세 스위치·키·운용 절차와 점검표는 `2026-10-17-local-arm-console.md`가 정본이다.
PR #14의 실물 성공은 사용자 확인 기록이며, 이번 이식 검증은 가상 장치로 수행한다.
